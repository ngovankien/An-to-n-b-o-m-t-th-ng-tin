BT3: RSA mã hóa/giải mã file + xác thực người gửi

Bước 1
Máy nhận tạo khóa, gửi receiver_public.pem cho máy gửi.
Bước 2
Máy gửi tạo khóa, gửi sender_public.pem cho máy nhận.
Bước 3
Máy gửi chọn file, mã hóa bằng public key máy nhận và ký bằng private key máy gửi.
Bước 4
Máy nhận upload package.bt3, xác minh chữ ký và giải mã file.

1. Tạo khóa cho máy nhận

Máy nhận giữ receiver_private.pem. Chỉ gửi receiver_public.pem cho máy gửi để mã hóa file.
Tải receiver_private.pem Tải receiver_public.pem
Chưa tạo khóa máy nhận.

2. Tạo khóa cho máy gửi

Máy gửi giữ sender_private.pem. Chỉ gửi sender_public.pem cho máy nhận để xác minh chữ ký.
Tải sender_private.pem Tải sender_public.pem
Chưa tạo khóa máy gửi.

3. Máy gửi: Mã hóa file + ký

Chọn file cần gửi. Nếu đã tạo khóa ở trên thì không cần upload key. Nếu làm trên 2 máy khác nhau, upload receiver_public.pem của máy nhận và sender_private.pem của máy gửi.
Tải package.bt3
Chưa tạo gói gửi.

4. Máy nhận: Xác minh + giải mã

Upload package.bt3 từ máy gửi. Máy nhận dùng sender_public.pem để xác thực người gửi và dùng receiver_private.pem để giải mã.
Tải file đã giải mã
Chưa giải mã.

Ghi chú nộp bài

Không dùng RSA để mã hóa trực tiếp file lớn. Cách đúng là hybrid encryption: AES mã hóa file, RSA mã hóa khóa AES. Xác thực người gửi được thực hiện bằng chữ ký số RSA-PSS/SHA-256.
Backend: Python server gọi C++ OpenSSL. Server lắng nghe 0.0.0.0:8000 để có thể chạy demo trong cùng LAN.
